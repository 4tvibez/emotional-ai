# Learning Path

Study the repository in this order:

1. server.js — HTTP server and routing
2. public/index.html — interface structure
3. public/style.css — visual design
4. public/app.js — browser events and fetch
5. src/emotions.js — classes and state
6. src/memory.js — persistence and async functions
7. src/personality.js — configuration
8. src/planner.js — decision logic
9. src/safety.js — guards and permissions
10. src/model.js — model adapter boundary
11. src/conversation.js — orchestration

Then upgrade one module at a time.

Suggested upgrades:
- unit tests
- database memory
- authentication
- real LLM provider
- streaming
- speech-to-text
- text-to-speech
- structured tools
- evaluation suite
- constrained robot adapter
